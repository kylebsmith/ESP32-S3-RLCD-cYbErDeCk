# cYbErDeCk v2 — a live-coding performance instrument

v1 proved the enclosure. v2 is the instrument: a standalone live-coding surface
with mapped physical control.

**Nothing in this folder touches v1.** The v1 enclosure, its parameters and its
check suite stay exactly as they are; v2 inherits the datums that were proven
(board, display, battery, ports) and re-opens everything else.

## Status

Research and layout exploration. No geometry frozen.

## Layout

| | |
|---|---|
| `research/` | precedents, control-surface theory, keyboard options |
| `parts/` | component datasheets, dimensions, 3D models |
| `layouts/` | SVG layout studies |
| `cad/` | v2 geometry, once a layout is chosen |
| `docs/` | decisions and their reasons |
